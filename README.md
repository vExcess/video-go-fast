# Video Go Fast

![logo](https://github.com/vExcess/video-go-fast/blob/main/images/icon-128.png?raw=true)

A minimal Chrome extension that controls HTML5 video playback speed from 0.25x to 3.00x.

Watch videos at 3x speed. No spyware. No adware.

Code written by Composer 2.5

## Features

- Slider with live speed label
- Increase/decrease buttons (0.25x steps)
- Reset to 1.00x
- Keyboard shortcuts (work with popup closed)
- Speed persists across tabs and browser sessions
- Automatically applies to dynamically added videos

## Install

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select this `video-speed-controller/` directory

## Keyboard Shortcuts

| Action | Windows / Linux | macOS |
|---|---|---|
| Open popup | Ctrl+Shift+Y | Alt+Y |
| Decrease speed | Ctrl+Shift+Left | Cmd+Shift+Left |
| Increase speed | Ctrl+Shift+Right | Cmd+Shift+Right |
